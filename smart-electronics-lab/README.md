# Smart Electronics Lab

Product design doc for a guided breadboard learning system that evolves into a
communications console and then an SDR workstation.

- `Smart_Electronics_Lab_v1.2_Product_Design.pdf` — formatted deliverable
- `Smart_Electronics_Lab_v1.2_Product_Design.docx` — editable version
- `Smart_Electronics_Lab_v1.2_Product_Design.html` — source; edit this and
  re-render the PDF/docx from it if the content changes

v1.2 integrates a second-reviewer consensus pass on v1.1 (see Section 0,
"What changed in v1.2," and Section 1, "Decision log," in the document
itself). Earlier versions are available in git history.
