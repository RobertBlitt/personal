# Smart Electronics Lab

Product design doc for a guided breadboard learning system that grows into a
three-kit product ladder: a quiet electronics lab, an internet-radio
capstone, an SDR/waterfall add-on, and a full SDR workstation — with a
no-code default path for every kit milestone.

- `Smart_Electronics_Lab_v1.4_Product_Design.pdf` — formatted deliverable
- `Smart_Electronics_Lab_v1.4_Product_Design.docx` — editable version
- `Smart_Electronics_Lab_v1.4_Product_Design.html` — source; edit this and
  re-render the PDF/docx from it if the content changes

v1.4 adds the no-code product architecture on top of v1.3's three-kit
ladder: three user paths (Use Mode, Configure Mode, Developer Mode), a
firmware delivery architecture with browser-based flashing as the default
install path, a proposed repository/release structure, a first-time user
flow, a configuration schema, a lesson-schema extension, a hard rule that
every required kit milestone must be achievable without writing code, and
a Claude/Codex build plan built around three explicit MVPs. See Section 0,
"What changed in v1.4," and Section 1, "Decision log," in the document
itself. Earlier versions are available in git history.
